# 📚 OCR Quiz & GK Assistant Bot

Ek powerful AI-driven Telegram Bot jo images aur bulk text se automatically MCQs aur Interactive Poll Quizzes generate karta hai, aur saath hi instant GK/GS doubts solve karta hai.

---

### ✨ Features
* 📸 **Scan Quiz:** Question paper ya book ke page ki photo bhejte hi instant Telegram Quiz Polls create karta hai.
* ✍️ **Text Bulk Quiz:** Ek sath questions paste karne par automated quiz format ready karta hai.
* 🧠 **GK/GS Assistant:** Koi bhi GK/Static GK sawal poochhne par fast aur direct jawab deta hai.
* ⏱ **Customizable Timer:** 10s, 15s, 30s ya Direct Click (No Timer) mode support.
* 📊 **Live Performance Card:** Quiz khatam hone par detailed scorecard aur accuracy report.
* 🔄 **24/7 Always Active:** Render par 24 ghante live rehne ke liye self-ping mechanism integrated hai.

---

### ⚙️ Tech Stack
* **Language:** Python 3.10
* **Framework:** `python-telegram-bot`
* **AI Engine:** Google Gemini (`gemini-3.5-flash`)
* **Hosting:** Render (Docker Container)

---

### 🔑 Environment Variables
Render dashboard par ye keys set hona zaroori hain:
* `BOT_TOKEN`: Telegram BotFather se generate kiya gaya token.
* `GEMINI_API_KEY`: Google AI Studio se mili API key.
